# Media Pembelajaran Interaktif Fisika Inti (Kenneth S. Krane)

Aplikasi web interaktif berbasis HTML5, Tailwind CSS, dan Chart.js yang dirancang sebagai media pembelajaran digital Fisika Inti berdasarkan buku teks **Kenneth S. Krane (*Introductory Nuclear Physics*)**.

## 🚀 Cara Upload ke GitHub Pages (Menjadi Web Online Gratis)

1. **Buat Repository Baru di GitHub:**
   - Buka [github.com](https://github.com) dan login ke akun Anda.
   - Klik tombol **"New"** (Repository baru).
   - Beri nama repository, contoh: `fisika-inti-interaktif`.
   - Pilih **Public**.
   - Klik **"Create repository"**.

2. **Upload File `index.html`:**
   - Di halaman repository baru Anda, klik link **"uploading an existing file"**.
   - Drag & drop file `index.html` yang ada di dalam package ini.
   - Klik tombol hijau **"Commit changes"**.

3. **Aktifkan GitHub Pages:**
   - Masuk ke menu **Settings** repository Anda.
   - Di menu sebelah kiri, klik **Pages**.
   - Pada bagian **Build and deployment** -> **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`.
   - Klik **Save**.

4. **Web Siap Diakses!**
   - Tunggu 1–2 menit, link web online Anda akan muncul di bagian atas halaman Settings Pages (contoh: `https://username.github.io/fisika-inti-interaktif/`).

## 📚 Fitur Utama Media Pembelajaran

1. **Modul 1: Sifat Dasar & Ukuran Inti Atom**
   - Kalkulator Jari-Jari Inti ($R = R_0 A^{1/3}$)
   - Visualisasi Model Bola Inti Atom 2D secara real-time.

2. **Modul 2: Defek Massa & Energi Ikat ($B/A$)**
   - Kalkulator Energi Ikat Total ($B$) dan $B/A$.
   - Grafik Kurva $B/A$ vs $A$ interaktif berbasis Chart.js.

3. **Modul 3: Gaya Antar-Nukleon & Sistem Deuteron**
   - Laboratorium Potensial Sumur Persegi ($V_0$ dan $R$).
   - Grafik Fungsi Gelombang Radial $u(r)$ dan penentuan *Bound State*.

4. **Modul 4: Peluruhan Radioaktif & Waktu Paruh**
   - Simulasi Peluruhan Kisi 100 Atom secara *real-time*.
   - Grafik Eksponensial Peluruhan $N(t) = N_0 e^{-\lambda t}$.

5. **Modul Evaluasi (Kuis Interaktif)**
   - Soal kuis berbasis konsep kunci Kenneth S. Krane.
   - Pengecekan otomatis, skor, dan pembahasan rinci.
